## 3. Detailed Accomplishments & Technical Highlights

### 3.1 Functional Requirements & Regulatory Mapping (`FR-001`–`FR-005`)

- Locked the five core functional requirements in `report/src/chapters/userRequirements.tex`:
  - **FR-001 (Data Ingestion)**: Ingestion and validation of FairFace annotations and demographic metadata.
  - **FR-002 (Model Interfacing)**: Zero-friction prediction ingestion via `ModelInterface` and `PredictionsFileInterface`.
  - **FR-003 (Disparity Computation)**: Pure mathematical and backend computation of Core Four disparity metrics.
  - **FR-004 (Statistical Rigor)**: Accompaniment of all metrics with 95% bootstrap CIs ($B \ge 1,000$) and $\chi^2$ significance tests ($p < 0.05$).
  - **FR-005 (Explainability & Reporting)**: SHAP-based feature attribution and standalone, zero-network HTML compliance reporting.

### 3.2 System Architecture & Flow Design

- Produced visual system diagrams illustrating the 5-module decoupled pipeline:
  $$\text{Data Ingestion} \longrightarrow \text{Model Interface} \longrightarrow \text{Fairness Engine} \longrightarrow \text{Explainability (SHAP)} \longrightarrow \text{Report Generator}$$
- Authored the comprehensive methodology chapter defining the mathematical formulation of Demographic Parity Difference (DPD), Disparate Impact Ratio (DIR), Equal Opportunity Difference (EOP), and Equalized Odds Difference (EOD).

### 3.3 Engineering Standards & Package Scaffolding

- Adopted PEP 517/621 `pyproject.toml` with UV package manager support.
- Configured Ruff rules (linting + auto-formatting) mirroring TA specifications: line length 88, double quotes, clean import sorting (`isort`).
- Scaffolded the source package structure:

  ```
  src/bias_aperture/
  ├── schema.py              # Locked demographic & metric dataclasses
  ├── model_interface.py     # InProcess & PredictionsFile interfaces
  ├── data_ingestion.py      # FairFace validation pipeline
  ├── fairness/              # Fairness metrics, backends & statistics
  ├── explainability.py      # SHAP proxy explainer
  ├── report/                # Jinja2 HTML report generator
  └── cli.py                 # CLI orchestration
  ```
