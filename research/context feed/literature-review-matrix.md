| **A Value for n-Person Games**<br>Shapley, 1953 (*Contributions to the Theory of Games II*) | Cooperative game theory — axiomatic allocation of the grand coalition's total gain among players | What unique allocation of a coalition's payoff satisfies a set of fairness axioms? | N/A (axiomatic theory) | Axiomatic derivation plus uniqueness proof over four axioms: Efficiency, Symmetry, Dummy, Additivity | Exactly one allocation satisfies all four axioms: φ_i = Σ_k W(k)·[v(S∪{i}) − v(S)], with permutation weight W(k) = k!(M−k−1)!/M! | The Shapley value is the unique axiom-consistent credit split; no other allocation satisfies all four axioms simultaneously | Theoretical bedrock of FR-005: feature attribution framed as fair credit division over a prediction's deviation from baseline (`docs/research/shap_explainability_and_weighting_principles.md` §2) |
| **A Unified Approach to Interpreting Model Predictions**<br>Lundberg & Lee, 2017 (NeurIPS) | Unified additive feature-attribution framework unifying LIME, DeepLIFT, and Shapley values | Can a single framework with local accuracy, missingness, and consistency properties unify prior post-hoc explanation methods? | N/A (methods paper, standard benchmarks) | KernelSHAP — attribution solved as weighted linear regression over feature coalitions, with Shapley kernel π(z') = (M−1) / [C(M, k)·k·(M−k)] | U-shaped kernel weights size-1 coalitions (main effects) and size-(M−1) coalitions (total interactive effects) maximally, down-weighting noisy mid-sized coalitions; LIME/DeepLIFT recovered as special cases | Shapley values computed via weighted regression are the unique consistent additive explanation for model-agnostic use | The approximation route for BiasAperture's deferred spatial attribution (`shap.PartitionExplainer`); kernel-weight derivation documented in `docs/research/shap_explainability_and_weighting_principles.md` §3.2 |
